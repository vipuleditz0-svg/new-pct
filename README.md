# VIPUL DELAY FX — Android starter project

This is an initial Android project for a real-time microphone/Android-routed audio delay effect.

## Build
Open this project in Android Studio, or push it to a GitHub repository and run the included
GitHub Actions workflow (`Build Android APK`). The generated debug APK is available as an
Actions artifact.

## Important
- This is an early prototype, not a finished professional pedal replacement.
- Audio behavior and latency depend on the Android device and USB interface.
- Use headphones for testing to avoid acoustic feedback.
- USB audio routing is handled by Android; compatibility varies by device/interface.
- The delay processing is mono at 44.1 kHz in this prototype.
